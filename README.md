## Overview

FabFilter Pro-L 2 is a comprehensive mastering limiter with eight limiting styles, true peak limiting, and high-quality oversampling for transparent and loud masters.

Whether you're a newcomer just getting started or a seasoned pro looking for advanced tools, **FabFilter Pro-L 2** delivers the features you need in a clean, intuitive package.

## Key Features

| Feature | Description |
|---------|-------------|
| **Eight Styles** | Transparent, dynamic, aggressive, bus, dynamic+, allround, live, and surgical |
| **True Peak** | True peak ISP detection for streaming-compliant masters |
| **Oversampling** | Up to 32x oversampling minimizes aliasing during limiting |
| **Stereo/M/S** | Full mid/side processing mode for mastering engineers |
